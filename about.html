關於本站

「KPOP 團體圖鑑」是一個給新粉絲的入坑指南。這個網站不是一頁一頁手工排版出來的，而是先寫好一份規則文件 CLAUDE.md，再讓 AI 依照規則產生每一個團體頁。所以每一頁的結構、配色方式、資料格式都一樣，之後要加新的團也很快。

每一頁都長一樣：9 個固定區塊

  1. Hero：團名與一句話介紹，背景是該團主色的「螢光棒光暈」
  2. 基本資料：出道日、經紀公司、粉絲名、人數、類型、出道曲
  3. 成員：藝名、本名與一個角色標籤
  4. 團體故事：組成背景與重要轉折
  5. 代表作時間軸：5–8 首，由舊到新
  6. 最新動態：標明「資料截至」日期
  7. 入坑推薦：剛好 3 首
  8. 小知識：可查證的趣事
  9. 資料來源：所有引用連結

要新增一個團時，AI 會怎麼做？

只要對 AI 說「新增 IVE」（在 Claude Code 中可以用 /add-group IVE），AI 讀完 CLAUDE.md 後會照這個流程：

1. 上網查證出道日、公司、成員、近況
2. 決定 slug（例如 Stray Kids → stray-kids）
3. 複製 templates/group-template.html → groups/<slug>.html
4. 依 9 個區塊規則填內容、設定主色
5. 在 assets/js/groups-data.js 依出道日順序登錄
6. 執行 node scripts/check.mjs 驗證
7. git commit -m "feat(group): add IVE"

首頁卡片、篩選按鈕、上一團／下一團導覽都是從 groups-data.js 自動產生的，所以新增一團只需要動兩個檔案。

自動檢查

scripts/check.mjs 會檢查：每個登錄的團都有頁面、每個頁面都有登錄、9 個區塊順序正確、沒有殘留的 TODO、主色與資料一致、「資料截至」日期與 updated 一致、沒有使用圖片。AI 每次改完都要跑過這支腳本。

內容原則

  • 不放偶像照片、專輯封面、團體 Logo、歌詞——用色彩和文字設計視覺
  • 成員與近況這類會變動的資訊，一律先上網查證並標日期
  • 不寫八卦與無來源的評價，語氣中立友善
